Komendy

    
Ustaw uprawnienia cyframi

      
chmod 744 plik.sh

      
7 = rwx dla właściciela, 4 = r-- dla grupy, 4 = r-- dla innych.

    
Dodaj prawo uruchamiania właścicielowi

      
chmod u+x plik.sh

      
Operatory: + dodaje, - zabiera, = ustawia dokładnie to, co podano.

    
Zabierz odczyt i zapis grupie oraz innym

      
chmod go-rw plik.txt

    
Sprawdź uprawnienia pliku

      
ls -l

      
-rwxr--r-- 1 user group 1234 Jan 1 12:00 plik.sh
 └┬┘└┬┘└┬┘
  │  │  └ inni: r--
  │  └──── grupa: r--
  └─────── właściciel: rwx

Użytkownicy i grupy

    
sudo uruchamia polecenie z uprawnieniami administratora.


    
Utwórz użytkownika z katalogiem domowym

      
sudo useradd -m jan

    
Ustaw hasło użytkownika

      
sudo passwd jan

      
Wpisz nowe hasło dwa razy. Znaki nie będą widoczne.

    
Utwórz grupę

      
sudo groupadd klasa

    
Dodaj użytkownika do grupy

      
sudo usermod -aG klasa jan

      
Nie pomijaj -a. Bez niego użytkownik może zostać usunięty z innych grup. Zmiana może wymagać ponownego zalogowania.

    
Usuń użytkownika z grupy

      
sudo gpasswd -d jan klasa

    
Zmień właściciela pliku

      
sudo chown jan plik.txt

    
Zmień grupę pliku

      
sudo chgrp klasa plik.txt

Procesy: kill i killall

    
Wysyłają sygnały do procesów, na przykład żeby je zakończyć.


    
Ćwiczenie na dwóch terminalach

    
Terminal 1: uruchom edytor i zostaw go otwarty

      
nano abc.txt

    
Terminal 2: wyświetl swoje procesy

      
ps x

      
  PID TTY      STAT   TIME COMMAND
 4321 pts/0    S+     0:00 nano abc.txt

      
Znajdź wiersz z nano abc.txt. Liczba w kolumnie PID to numer procesu. U Ciebie będzie inny.

    
Sposób 1: zakończ proces po PID

      
kill 4321

      
Zamiast 4321 wpisz PID znaleziony przez ps x.

    
Sposób 2: zakończ wszystkie procesy o danej nazwie

      
killall nano

      
Nie trzeba znać PID. Dotyczy wszystkich procesów o tej nazwie, które możesz kontrolować. Przed użyciem uruchom ponownie nano abc.txt w terminalu 1.

    
Wymuszone zakończenie (ostateczność)

      
kill -9 4321

      
Używaj, gdy zwykłe kill nie działa. Program nie zapisze danych ani nie posprząta po sobie.


    
Uwaga: jeśli w nano są niezapisane zmiany, zakończenie procesu może je zepsuć lub usunąć.
